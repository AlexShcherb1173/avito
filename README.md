# Backend приложение маркетплейса

## Описание проекта

Данный проект представляет собой backend-часть приложения маркетплейса, в котором пользователи могут размещать объявления, загружать изображения и оставлять комментарии.

Приложение реализует регистрацию пользователей, авторизацию, управление объявлениями, комментариями и изображениями.

Изображения сохраняются на сервере в файловой системе и могут быть получены через отдельный endpoint.

---

## Используемые технологии

- Java 11
- Spring Boot
- Spring Security
- Spring Data JPA (Hibernate)
- PostgreSQL
- MapStruct
- Swagger / OpenAPI
- Maven

---

## Основной функционал приложения

### Пользователь

- регистрация пользователя
- авторизация пользователя (Basic Auth)
- получение профиля пользователя
- обновление профиля пользователя
- смена пароля
- обновление аватара пользователя

---

### Объявления

- просмотр списка объявлений без авторизации
- просмотр конкретного объявления
- создание объявления (для авторизованных пользователей)
- редактирование объявления
- удаление объявления
- загрузка изображения объявления

---

### Комментарии

- просмотр комментариев объявления
- добавление комментария
- редактирование комментария
- удаление комментария

---

### Работа с изображениями

- загрузка изображений
- сохранение изображений на сервере
- получение изображений через endpoint `/images/{fileName}`

---

## База данных

В проекте используется база данных **PostgreSQL**.

Маппинг между Entity и DTO реализован с помощью **MapStruct**.

---

## Архитектура проекта

Проект построен по многослойной архитектуре:

- Controller — обработка HTTP-запросов
- Service — бизнес-логика приложения
- Repository — работа с базой данных
- Security — настройка авторизации и аутентификации
