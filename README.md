# Backend приложение маркетплейса

## Описание проекта

Данный проект представляет собой backend-часть приложения маркетплейса, в котором пользователи могут размещать объявления, загружать изображения и оставлять комментарии.

Приложение реализует регистрацию пользователей, авторизацию, управление объявлениями, комментариями и изображениями.

Изображения сохраняются на сервере в файловой системе и могут быть получены через отдельный endpoint.

---

## Используемые технологии

- Java 11
- Spring Boot
- Spring Security
- Spring Data JPA (Hibernate)
- PostgreSQL
- MapStruct
- Swagger / OpenAPI
- Maven
- Liquibase — управление схемой базы данных

### Комментарии

- просмотр комментариев объявления

## Рассказ о проекте

Данный проект представляет собой backend-часть сервиса объявлений, реализованного на базе Spring Boot.  
Приложение предоставляет REST API для работы с объявлениями, пользователями и комментариями.

Основная цель проекта — реализовать полноценный backend-сервис с системой аутентификации, управлением объявлениями и хранением изображений.

### Архитектура проекта

Приложение построено по многослойной архитектуре:

**Controller layer**
- AdController — управление объявлениями
- CommentController — управление комментариями
- UserController — работа с профилем пользователя
- ImageController — получение изображений

**Service layer**
- содержит бизнес-логику приложения
- реализует операции создания, редактирования и удаления данных

**Repository layer**
- реализован с использованием Spring Data JPA
- обеспечивает работу с базой данных PostgreSQL

### Работа с базой данных

В проекте используется база данных **PostgreSQL**.

Для управления схемой базы данных используется **Liquibase**.  
Liquibase позволяет контролировать изменения структуры базы данных и хранить историю миграций.

Маппинг между Entity и DTO реализован с использованием **MapStruct**, что упрощает преобразование объектов между слоями приложения.

### Система безопасности

В проекте реализована система аутентификации и авторизации с использованием **Spring Security**.

Используется Basic Authentication.

Реализованы роли пользователей:

- USER
- ADMIN

Система прав доступа позволяет:
- редактировать и удалять только собственные объявления
- ограничивать доступ к операциям изменения данных

### Работа с объявлениями

Пользователь может:

- получить список объявлений
- получить одно объявление
- создать объявление
- редактировать своё объявление
- удалить своё объявление

Также реализована загрузка и обновление изображений объявлений.

### Работа с комментариями

Пользователь может:

- получить список комментариев
- создать комментарий
- редактировать свой комментарий
- удалить свой комментарий

### Работа с изображениями

Изображения загружаются через `multipart/form-data` и сохраняются на сервере в файловой системе.

В базе данных хранится только путь к файлу изображения.

Для получения изображения реализован endpoint:

GET /images/{fileName}
