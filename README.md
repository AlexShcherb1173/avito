# Ads Application

Backend-приложение для размещения объявлений с поддержкой пользователей, комментариев,
аутентификации и авторизации. Проект реализован в рамках дипломной работы.


## Описание проекта

Приложение предоставляет REST API для:
- регистрации и аутентификации пользователей;
- создания, редактирования и удаления объявлений;
- добавления комментариев к объявлениям;
- управления данными пользователя (профиль, пароль, аватар);
- разграничения прав доступа (USER / ADMIN).

Аутентификация реализована с использованием **Basic Authentication**,
авторизация — на основе ролей пользователей.

## Архитектура проекта

Проект построен по классической слоистой архитектуре:

- **controller** — REST-контроллеры
- **service** — бизнес-логика приложения
- **repository** — доступ к данным (JPA)
- **entity** — сущности базы данных
- **dto** — объекты передачи данных
- **mapper** — преобразование DTO - Entity
- **config / security** — конфигурация безопасности

---

## Аутентификация и авторизация

- Используется **Basic Authentication**
- Пользователи хранятся в базе данных
- Пароли хэшируются с помощью **BCrypt**
- Реализованы роли:
    - `USER`
    - `ADMIN`
- Проверки прав выполняются:
    - через `SecurityFilterChain`
    - дополнительно в сервисах (для операций над чужими ресурсами)

---

## Работа с базой данных

- СУБД: **PostgreSQL**
- Миграции выполняются через **Liquibase**
- Все изменения схемы описаны в YAML-файлах
- Параметр `spring.jpa.hibernate.ddl-auto=validate`

## ▶ Запуск проекта

### 1. Запуск базы данных (Docker)

Для работы приложения используется PostgreSQL, запускаемый в Docker.

Если в проекте есть файл `docker-compose.yml`, выполните команду:

docker-compose up -d

Проверить, что контейнер запущен, можно командой:

docker ps

---

### 2. Запуск приложения

Приложение можно запустить одним из способов.

**Через Maven:**

mvn spring-boot:run

**Через IntelliJ IDEA:**
- откройте класс `HomeworkApplication`
- нажмите кнопку ▶ Run

## Документация API

В проекте используется спецификация OpenAPI для описания REST API.
Для просмотра и тестирования API подключён Swagger UI.

API защищено с использованием Basic Authentication.

Swagger UI позволяет просматривать доступные эндпоинты, их параметры,
а также выполнять тестовые запросы к API.

В документации представлены:
- эндпоинты объявлений (Ads)
- эндпоинты комментариев (Comments)
- эндпоинты пользователей (Users)
- эндпоинты аутентификации и регистрации
